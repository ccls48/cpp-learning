\# 我的 C++ 面向对象练习：技能伤害类



这是一个大二练习项目，用来记录我搞懂“构造函数、析构函数和深浅拷贝”的过程。



\##  为什么要写这个？

前几天手写链表的时候，经常忘了 `delete` 导致内存泄漏。最近学了类，发现把 `new` 写在构造函数，把 `delete\[]` 写在析构函数里，系统就会自动帮我管理内存，太爽了！



\## 踩坑记录

一开始没有写深拷贝构造函数，导致两个对象复制的时候，指向了同一个指针。程序结束的时候连续报了两次错（Double Free闪退），花了好久才明白是怎么回事。

加上自定义的深拷贝之后，问题完美解决！
